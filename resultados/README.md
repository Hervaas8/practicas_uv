# Carpeta `resultados`

Esta carpeta contiene los archivos generados durante la evaluación experimental del prototipo.

Incluye resultados en formato CSV procedentes de benchmarks, evaluaciones con modelos de lenguaje, análisis de similitud textual, comparación de modelos y evaluación de enunciados adaptados.

## Contenido 

- Resultados del módulo de evaluación automática.
- Resultados del generador de enunciados adaptados.
- Resultados de similitud semántica.
- Resultados de evaluación mediante juez externo.
- Resultados del detector de similitud textual.
- Resultados intermedios utilizados para generar gráficas.
