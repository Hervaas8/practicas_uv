# Carpeta `data`

Esta carpeta contiene los datos y recursos utilizados por el prototipo.

Incluye tareas en formato JSON, imágenes asociadas a las actividades, prompts, datos sintéticos, corpus externos y gráficas generadas durante el análisis experimental.

## Contenido habitual

- `json/`: archivos JSON con tareas, respuestas sintéticas y datos de evaluación.
- `img/`: imágenes utilizadas en las tareas del sistema.
- `img_pre/`: imágenes asociadas al test inicial o a tareas de navegación.
- `prompts/`: prompts utilizados por los modelos de lenguaje.
- `clough/`: corpus externo utilizado para evaluar la detección de similitud textual.
- `db/`: base de datos del sistema.
