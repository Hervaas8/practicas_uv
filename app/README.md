# Carpeta `app`

Esta carpeta contiene la interfaz web del prototipo, desarrollada con Streamlit.

Desde esta aplicación se gestiona la interacción con los distintos tipos de usuario, principalmente alumnado y profesorado. La interfaz permite iniciar sesión, seleccionar una sesión, realizar tareas adaptadas al nivel del alumno, mostrar imágenes o recursos asociados a cada actividad, recoger respuestas y visualizar los resultados finales.

## Ejecución

La aplicación debe ejecutarse desde la raíz del proyecto:

```bash
streamlit run app/app.py
